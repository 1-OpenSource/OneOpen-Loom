# Magicboard branding

Magicboard uses a **teal folio** mark, distinct from:

- **Loom suite** — slate interlaced weave (`docs/logo.svg`)
- **Workboard** — orange kanban (`docs/workboard/logo.svg`)

## Logo files

| Location | Use |
|----------|-----|
| [`logo.svg`](logo.svg) | Sphinx / README product mark |
| `magicboard/docs/logo.svg` | Product-local docs |
| `magicboard/frontend/public/` icon (if present) | SPA favicon |

## Guidelines

Full guidelines live in the product tree at ``magicboard/docs/brand.md`` (not part of this Sphinx toctree).

Summary:

- Accent: `#0f766e` (celadon teal)
- Do not recolor to Workboard orange (`#e86a17`)
- Do not replace the folio with kanban columns
- Avoid third-party proprietary wiki/product names in UI copy
