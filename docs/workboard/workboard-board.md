# Workboard (Kanban view)

The **workboard** is Workboard’s Kanban delivery surface for a project.

```{note}
Product name: **Workboard** · Board view name: **workboard**
```

## Stages

Default delivery stages:

1. To do  
2. In progress  
3. In review  
4. Done  

Drag cards between columns when a workflow transition allows the move.

## Blocked work

Mark an item **blocked** without moving it to a special column. The card stays in its stage and shows a blocked badge. Clear the flag when work can continue.

## Board settings

Configure:

- Column titles and WIP limits  
- Status ↔ column mapping  
- Custom transitions between statuses  

Project **Board** settings and workspace **Administration → Workflows** both touch this model.

## Sprints

For Scrum teams, create sprints, pull ranked backlog items in, and track them on a sprint board alongside (or instead of) a continuous Kanban flow.
