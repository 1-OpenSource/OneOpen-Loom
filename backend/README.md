# OneOpen Workboard Backend

This backend powers the OneOpen Workboard API for authentication, workspaces, projects, work items, comments, attachments, links, audit history, and search.

It uses FastAPI, SQLAlchemy, and Alembic, and it supports both SQLite and PostgreSQL through `DATABASE_URL`.

For setup, Docker, migrations, seeding, tests, and local run commands, see the repository [RUNBOOK](../RUNBOOK.md).
