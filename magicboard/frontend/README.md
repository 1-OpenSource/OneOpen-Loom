# OneOpen Workboard Frontend

React + TypeScript frontend for the OneOpen Workboard MVP.

## Runbook

```bash
npm install
npm run dev
```

By default the app expects the backend at `http://localhost:8000`. To change it, create `.env`:

```bash
VITE_API_BASE_URL=http://localhost:8000
```

The dev server usually runs at `http://localhost:5173`.
